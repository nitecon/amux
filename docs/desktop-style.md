# Amux desktop style

- Use the workspace theme for color, type, and spacing. Use regular-weight, leading-aligned action text with an icon when it helps identify the action.
- Use the existing rounded card surface for project rows, settings sections, and contextual actions. A blue outline marks the selected row or the open context menu. Reserve the filled accent for a primary action.
- Keep settings and focused workflows in the main panel. Put the available actions first and show muted, short supporting text beneath each action.
- Open platform folder pickers for filesystem choices. During a checkout, show the exact folder and a progress indicator, then keep the result in the same panel.
